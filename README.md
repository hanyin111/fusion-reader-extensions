# FusionReader 插件仓库

聚阅的独立来源插件。应用本体：[hanyin111/fusion-reader](https://github.com/hanyin111/fusion-reader)。插件使用跨平台 JavaScript，分发方式参考 Mihon 的独立扩展仓库和 Aidoku 的来源列表；格式为 FusionReader / Miru 脚本，不直接兼容其 APK 或 WASM 插件。

- 插件网页：<https://hanyin111.github.io/fusion-reader-extensions/>
- 仓库索引：<https://hanyin111.github.io/fusion-reader-extensions/index.json>

## 安装与更新

在聚阅 1.4.0 或更新版本打开「扩展 → 插件仓库」，选择插件安装。1.4.1 起需要先手动填写仓库索引地址。已安装插件会显示更新按钮，也可使用「更新已安装插件」。插件脚本下载并保存到本机，之后启动和离线阅读无需重新下载。升级旧版应用后，可使用「恢复旧版插件」安装原来的来源；原有书架、历史和插件设置保留。

网页可按类型和名称查找，复制仓库地址或单个脚本安装链接。应用也保留 URL 和粘贴脚本安装。

## Omofun 动漫

v1.1.1 在 FusionReader 1.4.2 及更新版本上使用官方 App 的公开读取接口，支持分类、搜索、分页、分集目录、HLS / MP4 播放、在线弹幕与作品评论，不需要网站账号。弹幕按作品和集数绑定，随播放进度分段加载；评论按整部作品提供，支持分页和查看回复。

旧网页版本收藏按完整标题尝试唯一匹配 App 作品，同名歧义会提示重新搜索。网站的旧网页解析仍保留用于兼容原有运行时。某些线路需要官方 App 专用加速组件，当前会提示换线；天堂线路已经完成真实播放检查。插件后续更新无需重新安装应用，首次使用此版需要更新本体以获得 gRPC 桥接和弹幕渲染能力。

## 瓜子影视

v1.0.1 使用 `gz360.tv` 网页的公开只读接口，支持电影、连续剧、综艺、动漫等分类、分页浏览、关键词搜索、完整分集目录、视频地址解析和作品评论。评论支持分页、点赞数和接口提供的回复；任意集数共用该作品评论，不需要网站账号。适用于聚阅 1.4.0 及更新版本，无需重新打包本体。

目录保存作品与分集 ID，播放时重新取得近期地址；接口限制一次返回的数量时，继续读取目录分页。网站标记为官方 App 专用的集数会明确提示，不能通过此插件解锁。网站广告、推荐外链、预告视频和每页重复的评论公告不作为正片或用户评论返回。快速重复刷新评论会短暂复用 15 秒内的成功结果。

本体已有弹幕渲染及插件数据接口，但当前官网桌面和移动播放器未配置弹幕请求或数据来源，所以此版未接入网站弹幕。播放器依赖中包含弹幕组件，不代表网站已提供可读取的弹幕数据。

加密库 aes-js 3.1.2 已随单个脚本内置，运行时不从外部加载代码；完整 MIT 许可同时附在脚本和 `licenses/aes-js-MIT.txt`。离线测试使用原创占位数据；实际联网检查可单独运行 `node tools/check_guazi.mjs`，不在 GitHub Actions 中访问站点。测试记录见 [docs/guazi.md](docs/guazi.md)。

## 发布插件

哔哩轻小说 v1.3.1 将正文、目录和评论请求串行执行，请求间隔至少 1.5 秒；相同请求合并，评论结果短暂复用 15 秒。遇到 403 等待后最多重试一次，持续限制时暂停后续请求 30 秒。这能减少快速阅读和重复刷新触发的限制，站点长期拒绝访问时仍需稍后重试或使用已缓存内容。

1. 修改 `sources/<package>.js`，保持 `@package` 不变，更新 `@version`。
2. 提交到 `main`。GitHub Actions 自动运行插件测试、生成索引并发布 GitHub Pages。
3. 用户在应用内刷新仓库并更新插件，无需重编译应用。

索引包含版本、类型、最低应用版本、脚本大小和 SHA-256；脚本发布为内容哈希命名的文件，避免索引和脚本缓存错位。客户端在加载前核对哈希和头部元数据。需要新的原生能力或改变运行时接口时，仍需要更新应用本体。

```sh
node --test tests/*.mjs
python -m unittest discover -s tools -p 'test_*.py'
python tools/build_repository.py
```

`public/` 是网页模板，`dist/` 是自动生成的发布目录，不提交生成产物。`fixtures/runtime.js` 是测试使用的应用桥接接口快照，不包含在插件分发中。
