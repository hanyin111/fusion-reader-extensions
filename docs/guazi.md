# 瓜子影视 v1.0.1

2026-10-13 核对官网 `https://gz360.tv/` 的公开前端请求，完成单文件插件。仅使用匿名内容读取接口，不注册设备、不登录、不写入网站数据，不调用广告、统计或推广接口。

## 已支持

- 最新列表及网站主要影视分类，每页 20 项，分类与搜索分别分页。
- 关键词搜索、作品标题、封面、简介和更新提示。
- 按分集序号排序的完整目录；服务器截断全量请求时补读分页，未完整返回则报错。
- 以作品 ID、分集 ID 保存章节引用，不把临时视频地址作为书架章节 ID。
- HLS / 普通视频地址及官网媒体请求头；播放时使用短暂缓存内的地址，过期后刷新。
- 官方 App 专用集数、空目录、接口变动等错误提示。
- 作品评论、每页 10 条、接口内附的回复、发表时间和点赞数；过滤每页重复的无 ID 网站公告。评论页短暂缓存 15 秒，回复以作品和父评论分别绑定。

仅改动独立插件。本体已有评论和弹幕能力，不需要升级；此版没有发评论、回复、点赞或登录网站的操作。

## 弹幕核对

核对公开桌面和移动详情页、两套播放器集成、公共接口封装及播放器依赖。xgplayer 依赖内带有通用弹幕组件，官网当前播放器配置没有接入弹幕数据，接口封装也未发现实际使用的弹幕读取请求。作品详情及分集返回未提供弹幕地址或标识，因此不填写虚构弹幕源、不把作品评论当作带播放时间的弹幕。此结论限于目前核对的公开网页接口，不代表未检查的官方客户端一定没有弹幕。

## 验证

- 新增 18 项离线测试，与独立插件项目其余测试合计 56 项通过；包含评论末页、空评论、回复关联、缓存到期和重复分页保护。
- 在应用现有 Windows QuickJS 动态库中核对脚本加载、中文和 emoji 的 AES-CBC 编解码、异步请求与结果映射，通过。
- 实际联网读取 11 个入口，动漫第一页和第二页各 20 项，搜索有对应结果；核对一集电影及三集系列动画的完整目录与不同集的地址。
- 电影 HLS 清单包含 553 个片段，清单正常返回；分片范围请求取得 1024 字节。仅验证读取链路，没有据此声明手机画面、音频、硬件解码或长时间播放已测试。
- 仓库索引生成与脚本大小、SHA-256 检查通过。
- 匿名作品评论首、第二页各 10 条；示例作品共 261 条，末页 1 条，回复来自原评论内附的 children；另核对一部实际无评论的作品，过滤公告后显示为空。这些数字仅记录检查时结果，不是固定断言。
