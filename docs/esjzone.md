# ESJ Zone

## v1.2.0：章节评论

2026-10-13 接入官网章节页面的评论。软件已有 `@comments chapter` 协议及入口，更新插件后可在目录的章节右侧、小说阅读菜单中查看，无需重新编译本体。

- 官网将评论及所有分页的 HTML 一并放在章节页中，并在浏览器里每页显示 15 条；本插件按相同顺序分批返回，不访问发帖、点赞或举报接口。
- 显示用户名、时间、正文及图片，过滤头像、楼层、举报与回复按钮。引用回复按官网方式作为普通评论展示，保留引用内容；不虚构独立回复数或回复接口。
- 从整个评论正文容器读取，兼容网站在 `p` 标签内部放置 `div` 时浏览器会调整标签位置的情况；脚本、样式等不作为正文显示。
- 刚读取的章节可复用 15 秒内的页面数据；同时打开同一评论页合并请求，快速刷新复用 15 秒内的成功结果，后续分页复用最多 2 分钟的同一快照。缓存只在内存中保留，最多 6 个讨论页；不新增离线评论存储。
- 校验章节属于对应作品，拒绝外站或无效地址。正常的空评论区返回空列表；缺少评论区的登录页或异常页返回错误，不伪装成没有评论。

### 验证

- 新增 9 项评论测试：入口声明、分页与去重、引用与图片、空列表与登录墙、地址校验、正文页面复用、并发与刷新、失败重试、缓存上限。插件仓库全部 75 项 JavaScript 测试通过；索引测试及构建通过。
- 直接运行修复后的脚本与真实站点交互，基准作品的序章及下一章分别读取到 11、10 条评论；用户名、时间和正文均有效。
- 用同一作品详情讨论作为多页 HTML 样本，读取到 330 条；前两页各 15 条，ID 不重叠，引用内容保留。运行时支持无章节地址时回退到详情讨论，但当前软件的 ESJ 入口按章节显示。
- 目录 293 章、搜索和封面及正文继续通过原有联网检查。本次检查共 10 次站点请求，未写入评论或保存用户网页；测试仅打印数量，不输出账号、Cookie、令牌、用户留言或小说正文。
- 联网检查使用与应用一致的请求及 CSS 桥接数据形状；实际手机上的交互效果由安装新版插件后测试确认。

## v1.1.1：登录与封面

2026-10-13 以用户指定的 `https://www.esjzone.cc/detail/1719825699.html` 为基准核对。

## 问题与修复

- 当前网站的访客页面仅显示原创作品。目标翻译小说在未登录时返回论坛页面，HTTP 状态仍为 200；这不能直接当成小说数据。
- 原插件仅在详情和正文尝试登录，列表、搜索没有登录，所以翻译作品不会出现在列表中。
- 官网表单在提交账号前调用同页 `plxf=getAuthToken`，读取 JinJing 包装内的令牌，再用 authorization 请求头提交登录。原插件遗漏此步骤，且误将状态 301 当成成功。新版只接受状态 200，并以会员页面确认 Cookie 有效；不执行网站下载的 JavaScript。
- 列表封面位于 `.main-img` 的懒加载 `data-src` 中；详情封面位于 `.product-gallery img`。原插件固定返回空封面，新版提取真实地址，保留无封面作品的空值，不拿头像或网站 Logo 代替。
- 最新、搜索、详情和正文共用登录流程；并发调用合并登录请求，站点会话失效后最多重新登录并重读页面一次。明确的登录错误不会被吞掉。
- 增加日轻、韩轻和原创分类；原收藏入口及账号设置键保持兼容。

## 验证

- 新增 10 项针对性测试，包含令牌先于密码提交、失效状态 301、登录并发、缺少凭据、Cookie 失败、懒加载封面及翻译列表路由；独立插件项目全部 66 项 JavaScript 测试通过。
- 直接运行修复后的插件，通过与应用兼容的网络和 CSS 桥接读取官网。授权登录有效；最新列表 40 项全部带封面；搜索定位到基准作品并带封面；详情目录为 293 章。
- 基准封面请求得到 HTTP 200，返回可识别的图片字节；未生成或发布作品图片。
- 抽查序章及下一章，正文分别为 358、5470 字符，均非空。数字仅代表检查时结果，不作未来固定保证。
- 测试账号仅通过标准输入和内存使用，代码、报告和分发内容不包含账号、密码、Cookie、令牌或用户数据。联网检查不在 CI 中执行，也不保存实际网页和正文。
